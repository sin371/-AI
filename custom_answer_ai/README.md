# 커스텀 답변 AI

내가 말하는 질문에 대해, **내가 미리 정해둔 답**을 그대로 돌려주는 간단한 웹앱입니다.
자유 생성형 LLM이 아니라, 등록된 질문-답변 쌍 중 가장 비슷한 질문을 찾아 그 답을 반환하는 방식입니다.

## 실행 방법

```bash
cd custom_answer_ai
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:5000 접속.

## 사용법

1. **답변 관리** 탭에서 질문과, 그 질문에 대해 원하는 답을 등록합니다.
2. **질문하기** 탭에서 등록한 질문과 똑같이(또는 비슷하게) 물어보면 등록해둔 답이 그대로 나옵니다.
3. 표현이 조금 달라도(어순, 조사, 일부 단어 차이) 유사도 매칭으로 같은 답이 나올 수 있습니다.
4. 등록된 질문과 충분히 비슷하지 않으면 "등록된 답변이 없다"는 안내와 함께, 새로 등록하라는 메시지를 보여줍니다.

## 동작 원리 (matcher.py)

- 문자열 유사도(`difflib.SequenceMatcher`)와 단어(토큰) 겹침 비율(Jaccard) 중 더 높은 값을 사용
- 유사도가 임계값(기본 0.45) 이상인 등록 질문 중 가장 높은 것을 선택
- `matcher.MATCH_THRESHOLD` 값을 조절해 더 엄격하게(오탐 줄이기) 또는 더 관대하게(매칭 잘 되게) 할 수 있습니다.

## 데이터 저장

`data/qa_data.json` 파일에 질문/답변이 저장됩니다. 앱을 재시작해도 유지됩니다.

## API

| Method | Path | 설명 |
|---|---|---|
| GET | `/api/qa` | 등록된 질문/답변 목록 조회 |
| POST | `/api/qa` | 질문/답변 등록 (`{question, answer}`) |
| PUT | `/api/qa/<id>` | 질문/답변 수정 |
| DELETE | `/api/qa/<id>` | 질문/답변 삭제 |
| POST | `/api/ask` | 질문 → 매칭된 답변 반환 (`{question}`) |
